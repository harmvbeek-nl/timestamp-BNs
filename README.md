# What Time Was It, and Why? A Formal Framework for Tackling Incomplete Timestamps.

This repository contains the Bayesian Networks (BNs) to support infering missing timezone information for the Exif and Syslog examples.
The BNs are available as HUGIN object oriented net files (.oobn) and can be opened with the software Hugin Lite 9.7, available at https://www.hugin.com/hugin-lite/.

Next to the Bayesian Networks themselves, the screenshots folder contains several screenshots of instantiations of the BNs in the Hugin Lite application.
